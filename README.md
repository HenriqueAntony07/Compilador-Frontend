# Compilador Frontend

Ferramenta front-end para converter HTML/CSS/JS em projetos Next.js, React/Vite, PHP front-end ou HTML organizado.

## Como usar

1. Abra `index.html` no navegador.
2. Cole seu HTML, CSS e JS ou carregue arquivos separados.
3. Escolha o destino.
4. Clique em **Compilar projeto**.
5. Baixe o ZIP e abra no VS Code.

## Observacao

Esta versao e 100% front-end e funciona sem servidor. Ela converte por regras heuristicas. Para usar IA real com upload de ZIP completo, a arquitetura recomendada e adicionar um backend Node.js com OpenAI API para leitura do ZIP e refatoracao dos arquivos.
